# RR Regatta

Tattico di bordo basato sul GPS del telefono o del tablet, sviluppato per Round Robin A.S.D.

## Stato

**Versione 0.1: pagina diagnostica GPS.** Serve a verificare, sul telefono reale, che il browser riceva la posizione e a individuare permessi o impostazioni mancanti. L'applicazione di regata verrà ricostruita a partire da qui, una funzione alla volta.

## Uso

Aprire il sito con Chrome su Android, premere «Avvia GPS» e consentire la posizione. Il pulsante «Copia il rapporto» prepara un testo da inviare a chi sviluppa.

Nessun dato viene inviato a server esterni: tutto resta nel browser del dispositivo.
